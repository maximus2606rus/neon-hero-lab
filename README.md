# AI Vision Hub

Создай Нero-секцию для лендинга-портфолио специалиста по вайбкодингу. Используй визуальный стиль, цветовую палитру и композиционные решения загруженного референса. Применить темную тему цветовую схему с акцентными неоновыми элементами. Основной заголовок: "Создаю АИ". Подзаголовок: "Быстро собираю MVP".  Разместить две основные кнопки с четкими акцентами: - "Посмотреть проекты" (оранжевый акцент) - "Связаться" (фиолетовый акцент). В правой части Hero разместить визуальный элемент в стиле референса - фрагмент интерфейса или дэшборда.  Обеспечить качественную адаптацию под мобильные устройства, сохранив читаемость и удобство взаимодействия. Остальное не трогай
